# Capability Stitch

1. Temukan tool desain Stitch yang diekspos host; gunakan metadata dan skema aktual.
2. Jika tidak tersedia, nyatakan belum terhubung. Environment variable saja tidak membuktikan koneksi.
3. Jika diminta memasang konektor, periksa dokumentasi resmi host/Stitch sebelum mengubah konfigurasi. Format autentikasi/interpolasi dapat berbeda.
4. Gunakan secret store atau referensi environment yang didukung. Jangan tulis/cetak key ke repo atau brief.
5. Uji koneksi dengan operasi baca jika tersedia. Operasi eksternal mengikuti otorisasi pengguna/host.
6. Simpan hanya referensi proyek/layar/export aktual dan status hasil.

Tanpa tool, siapkan brief melalui phase-3a dan ikuti fallback phase-3-frontend. Jangan mengarang tool, URL export, atau konfigurasi autentikasi.
