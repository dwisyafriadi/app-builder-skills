# Frontend lokal

Nama dipertahankan untuk kompatibilitas; Tailwind/Next.js bukan kewajiban.

1. Baca komponen, styling, routing, praktik aksesibilitas existing.
2. Implementasikan layar/tindakan yang diminta dengan state data dan validasi relevan.
3. Hubungkan kontrak data aktual. Mock hanya untuk demo/desain berstatus jelas, bukan integrasi selesai.
4. Gunakan kembali komponen yang sesuai; jangan mengganti design system untuk fitur/bug biasa.
5. Periksa navigasi, keyboard, label, error, viewport kecil/besar yang relevan, dan overflow.
6. Jalankan pemeriksaan frontend tersedia. Jika browser tidak tersedia, nyatakan pemeriksaan visual belum dilakukan.

Tidak ada route toko, batas halaman, locale, atau currency yang dipaksakan.
