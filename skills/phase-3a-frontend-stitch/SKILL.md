# Stitch

Baca [capability Stitch](../app-builder-id/references/mcp-stitch.md) ketika membutuhkan integrasi.

Brief berisi tujuan, role, flow, layar/route, tindakan/data, komponen/gaya existing atau arah visual yang diminta, contoh konten realistis, target viewport, state loading/kosong/error/sukses, batas MVP, dan kriteria penerimaan. Jangan sertakan secret/data pribadi nyata.

Gunakan tool yang benar-benar tersedia; simpan referensi proyek/layar/export aktual. Jangan mengarang ID atau mengklaim ekspor yang tidak dikembalikan tool.

Periksa kesesuaian hasil dengan scope, role, flow, dan data. Adaptasi hasil generator ke stack proyek; desain bukan kontrak backend. Jika tool gagal/tidak tersedia, nyatakan status dan ikuti [fallback UI](../phase-3-frontend/SKILL.md). Brief bukan bukti desain telah dibuat.
